## 2. 比较对象必须先固定

在决策时刻 `t`，采用完整模型持仓数量 `Q` 和同一报价单位 USDT。比较的是“从现在开始的未来差异”，已经发生的买入费用是两种行动共享的沉没成本，不能只对其中一种行动重复收费。

两个行动必须使用同一估值基准、费用体系和未来观察区间：

1. `EXIT_NOW`：按同场所、当前可验证的完整 bid 深度退出 Q；之后现金保持 USDT，不加入“腾钱买下一个币”的收益。
2. `HOLD_POLICY(pi)`：继续持有同一 Q，执行预先冻结的后续管理策略 pi。建议首个离线版本专门比较现有数量，不假设新增资金；一旦允许未来 ADD，必须另建包含全部现金流的比较模型，不能混用两种标签。

pi 应明确保留哪些既有未来退出：例如 Profit Protection、已批准的 HARD_INVALIDATION 和盈利 thesis 退出。新 REBOUND 风险退出不能出现在训练标签的 hold 对照中，否则会循环论证。历史遇到 ADD 时不能简单剔除“表现不好的样本”；应记录不适用或按预注册的全现金流模型处理，并披露选择偏差。

`H` 是统计评价期限，不是持有到期自动卖出的指令。若 pi 在 H 前退出，剩余期间按退出现金估值；若 H 时仍持仓，以当时完整盘口净清算估值作为研究标签。这个终值仅在离线研究文件中存在，不生成 SELL 或时间止损。

## 3. 费用和执行不确定性

当前静态盘口的净退出现金为：

`E0 = sum(bid_price_i * quantity_taken_i) * (1 - sell_fee)`。

其中 `sum(quantity_taken_i)=Q`；不满足完整数量、身份、单位、时间或手续费验证时，结果为 `UNKNOWN`。若已经使用 bid VWAP，相对于 mid 的 spread 和吃单深度滑点已经体现在现金值中，不能再重复减去一个通用 spread/slippage 百分比。

单张盘口只是一个报价时点。应另行研究执行误差带 `E in [E_low, E_high]`，误差来源至少拆成：

- 采集、传输、决策及模拟执行延迟；用真实 request-start / response-end、exchange timestamp（若有）和随后盘口序列校准。
- 档位撤单、深度补充和价格变化；用连续公共数据估计同样数量在预注册延迟条件下的报价清算变化。
- 费用模型差异、数量舍入、最小成交量及场所过滤规则。
- 无法由公共快照识别的市场冲击；必须单独列出假设和敏感性区间，不能声称已通过真实成交验证。

当前五分钟采样不能识别亚秒至数秒执行损失分布。没有经过覆盖校准的误差带时，只能输出静态影子估值，风险比较状态继续 `UNKNOWN`。禁止用任意固定滑点常数把缺口“补齐”后称为实测。

未来数据采集仍应限公共只读来源，不通过真实下单测量冲击。用报价序列得到的校准只能支持影子执行模型，不外推到真实交易。

## 4. 风险判定：先采用严格占优，而不是隐含的风险偏好

令 `W_E(H)` 为 EXIT_NOW 在 H 的净现金；令 `W_H(H)` 为冻结 pi 下继续持有的净终值。二者都包含各自退出成本和执行误差，使用同一场景配对。定义：

`D = W_H(H) - W_E(H)`。

`D < 0` 表示该场景继续持有比立即退出更差。原买入价格只用于判断当前是否亏损、审计原 thesis，不进入“必须回本才卖”的决策条件。

再选相同基准 `M = Q * contemporaneous_mid`，定义两种行动的终值损失 `L_A = M - W_A(H)`；以用户明确选择的尾部水平 alpha 计算 `ES_alpha(L_A)`。研究可另报期间最大净值回撤，但不得把“最大回撤的 ES”和“终值 ES”混称同一个风险量。

首个候选规则建议使用两个条件的交集，不设隐含收益/风险兑换率：

`U_mu = 最保守允许执行/模型设定下，E[D | 当前合格状态] 的单侧上界`

`L_risk = 最保守允许执行/模型设定下，ES_alpha(L_H) - ES_alpha(L_E) 的单侧下界`

只有 `U_mu < -margin_value` 且 `L_risk > margin_risk`，才能标记为 `EXIT_DOMINATES_IN_SHADOW_MODEL`。也就是说，证据必须同时支持：继续持有的预期净值更差，而且尾部损失更大，差异超过明确预注册的实质性门槛。

“最保守”针对授权退出：在合理误差范围内尽量给 HOLD 有利估计、给 EXIT 不利估计，再看占优是否仍成立。应优先对配对差值构造区间，保留两行动的共同市场因素，而不是把两个独立样本误差直接相减。

这些是条件分布参数的统计区间，不是单笔交易必然结果的界限。另行保存 D 的预测区间及其样本外覆盖情况；不能把均值置信区间写成“95% 保证这个仓位应卖”。若区间重叠、模型漂移、有效样本不足、成本区间无界或关键证据未知，输出 `UNKNOWN` 并继续仅审计。

若用户以后希望“牺牲部分正期望收益来减少尾部风险”，这是另一种效用函数和策略选择，需要明确的风险厌恶参数与单独验证；不能偷偷使用入场 RR=1.5 或支撑/阻力比实现。

区间可采用按市场日期与持仓 episode 分组的配对 block bootstrap，再做时间留出的预测覆盖校准。不能把同仓每五分钟记录当 IID 重采样。金融序列的相关和分布漂移会影响区间覆盖；conformal 方法也需要清楚说明适用假设，不能直接声称分布无关保证。[Barber 等：Conformal prediction beyond exchangeability](https://arxiv.org/abs/2202.13415)

## 5. 反弹、thesis 与 HARD_INVALIDATION 是不同判断

风险比较只在以下可审计条件全部成立时进入离线候选评估：

- 当前净清算估值为亏损；原仓位身份和原 thesis 可追溯。
- 已批准的“thesis 维护契约”返回 `NOT_RECOVERED`，且足够多个独立来源周期显示持续弱化。维护契约应列出原始关键假设、当前证据要求及恢复/未恢复/未知的判定；不能直接复用全部入场阈值作为持有条件。
- 当前 asset/BTC 来源对齐、相对强弱仍弱，已完成 K 线结构及需求证据仍弱；处理时间变新不能刷新旧来源证据。
- 出现有时间边界的反弹窗口：已观察到从局部弱势阶段的改善，随后出现已完成 bar 的需求/动量失速；当前盘口清算值的改善应超过校准的报价噪声。反弹幅度是特征，不能单独成为固定 X% 卖出触发器。
- 正在形成的 bar 只可提供恢复否决信号，不用其低成交量证明恶化。当前恢复证据、thesis 恢复或相对强弱转好均否决旧反弹退出窗口。
- 完整数量退出估值有效，候选及 fundamental/supply/venue 证据有效；窗口过期后只取消评估，不产生时间退出。

HARD_INVALIDATION 使用独立、已批准的事实证据与原因链，例如来源可靠的场所/资产重大失效事实。价格跌幅、模型判断 HOLD 较差、反弹乏力、数据缺失或未证实风险都不能升级为 HARD_INVALIDATION。现有 hard 路径不由此统计模型授权，也不应因模型缺样本而被误当作普通 thesis weakening。

非 HARD 情形的亏损退出本身属于需明确确认的策略扩展。本文和任何离线 `EXIT_DOMINATES_IN_SHADOW_MODEL` 标签都不构成启用授权。运行 Gate 保持关闭；即使所有研究条件为真，也不得生成正式 SELL。

## 7. 预注册和样本外离线验证

先冻结数据字典、episode 定义、pi、H、费用/延迟假设、模型、调参预算、退出门槛、主要指标和失败标准，保存批准记录、代码 SHA 和配置摘要。ENA/PENDLE 是已知问题的诊断样本，不能反复用它们调到出现历史 SELL 后再称为样本外成功。

按时间推进划分开发、校准和最终留出区间；同 episode、同资产高度重叠路径以及共同市场冲击不拆成独立训练/测试样本。所有训练标签必须在测试决策时已成熟，跨越分割点的未来标签执行 purge；embargo 和特征/标签重叠规则预注册。模型改动后使用新的未看过留出区间，不反复重用失败的测试集。

每五分钟反复检查也属于重复检验，不能无限等待某一轮普通置信区间恰好通过。首个离线版本应预注册每个 episode 的首个合格评估点；其他轮仍记录状态，但不能事后挑最好退出点。若未来允许多次统计授权，必须另行预注册并验证序贯检验或 alpha spending，记录全部检查次数，不能把同一次校准反复使用而不控制可选停止偏差。

主要评估至少包括：净配对差值与尾部风险区间、区间覆盖、错误退出后 thesis 恢复/显著反弹比例、错过退出的后续损失、UNKNOWN 比例、数据缺失敏感性、按场所/流动性/市场状态分组结果、换成本与延迟情景后的稳定性。保留尝试过的全部候选模型与参数版本，不能只展示胜出模型；大量搜索本身会造成回测选择偏差。[Bailey 等：The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

现有两仓历史不足以校准尾部风险。示例：即使有 50 个独立 episode，在 95% 尾部下也仅约 2.5 个预期尾部样本，不能靠数千个相关 Monitor 行把区间虚假缩窄。最低有效样本量应由用户选定的 alpha、允许误判率及预注册精度/功效目标决定。

通过离线验证后，也只进入未来只读影子观察：持续生成研究标签与误差反馈，不写正式 events。模型资格、数据资格和用户启用授权应分别存储；任何一个缺失都保持运行 Gate 关闭。

下面数字仅用于构造单元/离线测试，不是生产参数。测试案例可暂设 `margin_value=2U`、`margin_risk=3U`，但不得由测试配置写入运行规则。

| 完整研究占优但未授权 | E[D] 区间 -22 至 -12U，ES 差区间 +8 至 +18U，其他研究条件成立 | 可记录 `EXIT_DOMINATES_IN_SHADOW_MODEL`，但 `exit=false`、正式 SELL=0 |
| 当前恢复推翻旧窗口 | 旧已完成 bar 显示反弹失速，当前有效 partial bar 显示恢复，或原 thesis 已恢复 | 取消退出评估；不是旧窗口优先 |
| 部分 bar 低成交量 | 当前 bar 只走了 10%，累计量低于上一完整 bar | 不得认定需求恶化 |
| 买入价与资金干扰 | 两个相同 Q/同当前状态的仓位入场价不同，或一个组合缺资金 | 前瞻 D 风险比较应相同；不能为腾资金改变退出结论 |
| 假大样本 | 同一 episode 的每条记录复制十次 | 有效样本量、置信区间不得因此缩窄 |
| 反复窥视直到通过 | 同一 episode 连续试 100 次普通区间，事后只保留唯一通过的一轮 | 验证失败；须遵守首个评估点或已注册序贯规则 |
| 来源偷换 | Binance 盘口估算 Bybit 仓位，或旧数据换新 fetched_at | `UNKNOWN`；不借同名资产跨场所证明可执行性 |
| 信息泄漏 | 用 t+H 已公布的解锁消息作为 t 的 feature | 数据验证失败，整个样本外结果失效 |
| 缺失最差时段 | 删除暴跌时盘口不可用 episode | 验证失败；必须保留缺失和敏感性结果 |
| HARD 与普通弱化混淆 | 仅价格跌 20% 或持有多天，无事实失效证据 | 不能 HARD_INVALIDATED，也不能机械 SELL |
| generation 重放 | 同源周期重复执行、较旧来源在较新处理时间到达 | 决策状态不重复推进，正式 SELL=0，不追加重复研究事件 |

本方案的当前结论仍为：模型未验证，必要策略选择未批准，执行 Gate 保持关闭。研究产物应单独保存模型版本、数据范围、各条件真假/未知、所有区间、缺失项和明确 reason，不修改历史真实事件。
