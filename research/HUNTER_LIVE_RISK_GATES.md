# Hunter 交易所上线风险门槛（未启用）

记录日期：2026-10-05。适用于将来评估 V1、V2 是否能从影子研究转入 Bybit 现货自动交易。当前 `capital_authority=NONE_SHADOW_ONLY`；本文件不授权真实下单，不改变当前资金上限或影子策略参数。

## 优先级与硬边界

1. 本金安全 > 控制最大回撤 > 已实现利润保护 > 寻找新利润。候选的预期涨幅不能覆盖任何风险门槛。
2. V1 是广网研究样本且当前无影子总资金上限；不能直接复制 V1 持仓或以影子收益作为实盘准入。V2 也须独立通过长期前向验证、异常场景、订单生命周期与人工 capital review。
3. 实盘前须批准独立的可承受损失资金池、单币最大风险、组合最大敞口与回撤暂停线。已实现利润和本金分账；不得因影子盈利自动扩大真实风险额度。极端情况下把山寨仓位按可能损失全部本金估算。任何门槛缺失即阻止新买。
4. 交易所止损只提高及时响应能力；触发价不是保证成交价。系统必须记录滑点、部分成交、订单拒绝和剩余风险，绝不把触发或 API 接受回执写成已经卖出。

## 买入成交与止损覆盖

- 买入决策时先计算有依据的止损触发价、仓位数量与含费用/滑点的风险预算。止损价必须低于入场价且符合交易所价格、数量规则；缺少可靠结构或风险预算时拒绝入场，不以随意固定百分比替代。
- 对支持预设 TP/SL 的 Bybit 现货限价买单，优先随买单设置止损；任何其他买入方式都不得将“随后再挂止损”误认为无保护间隙。只有买单实际成交且交易所确认对应止损订单有效、数量覆盖实际持币后，状态才是 `PROTECTED`。
- API 请求被接受不等于订单已生效；需按订单 ID 查询/WebSocket 确认状态并与持币余额对账。止损拒绝、超时、被取消、数量不足、行情/连接失效时为 `UNPROTECTED`：冻结本策略所有新买和加仓、报警、尝试应急退出并继续核对剩余敞口。不能虚报为安全或虚构成交。
- 加仓或部分卖出后更新止损覆盖的实际剩余数量；修改止损时不得留下未保护窗口。重启后从交易所订单和余额恢复，而非仅信任本地账本。止损触发后持续跟踪部分成交与未成交数量，按实际成交价与费用记账。

## 止损后重新买入

- 止损成交后，同币立即进入 `STOPPED_REENTRY_BLOCKED`。旧 BUY 信号、旧候选排名、价格便宜、固定冷却时间结束或单次反弹，都不能自动买回；禁止下跌时用自动加仓摊低成本。
- 可重新评估的必要条件：新一轮独立发现/新信号；BTC 急跌风险解除且不继续加速下跌；该币出现可验证的止跌与相对 BTC 转强；新鲜订单簿深度、价差、滑点仍可执行；全局回撤与风险预算允许；新买单有新的止损方案。全部成立后也只是重新进入完整 BUY 审核，不保证买入。
- 若 BTC 仍急跌、市场普跌、流动性恶化、证据缺失或多次止损，继续封锁新买并升级组合熔断。反弹收益排在本金风险之后。解锁条件与阈值须经前向影子测试和人工审核确定，不能为了提高买入率自动放宽。

## 上线验收与状态

影子阶段模拟：成交即设止损、拒单/断线、部分成交、加仓覆盖、止损后再次出现 BUY、BTC 单日急跌且山寨跳空/流动性枯竭。区分“止损触发”“交易所确认”“实际成交”；报告未成交仓位与最坏情景敞口。实盘接入须另行验证 Bybit 现货订单类型及账户权限、测试环境和小额隔离运行，并经用户单独明确授权。目前状态：**仅规范和验收门槛，未实现交易所挂单，也未开放实盘交易**。
